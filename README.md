# C Programming Lab — Sajjad Shaikh

**Course:** VSEC102 — C Programming Lab  
**Institute:** Rizvi College of Engineering  
**Academic year:** 2026–2027

This repository contains C source files organized according to the 11 experiment aims in the supplied lab manual.

## Experiments

1. Input, output and operators
2. Sum of odd numbers between two entered numbers
3. Menu-driven student grade and result management using `switch` and `goto`
4. Prime numbers between two numbers using functions
5. Fibonacci series using iterative and recursive methods
6. Function-call counter using storage classes
7. Largest element in an array and sum of two matrices
8. String length without a library function and palindrome check
9. Student records using a structure; display the topper among five students
10. Add two numbers using pointers and print an array in reverse using pointers
11. Simple employee database using file handling

## Compile and run

Use GCC or Code::Blocks with MinGW. Example:

```bash
gcc Experiment_01/experiment_01.c -o experiment
./experiment
```

On Windows, run `experiment.exe` after compiling.

The three assignment sections in the supplied manual have blank question fields, so the `Assignments` folder contains a note rather than invented answers. Review each program, test it, and adapt it to your instructor's exact requirements before submission.
